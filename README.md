## Supported Image Formats

This tool supports two-way conversion between the following formats and extensions:

| Format | File Extensions |
| :--- | :--- |
| **PNG** | `.png` |
| **JPEG** | `.jpg`, `.jpeg` |
| **WebP** | `.webp` |
| **Bitmap** | `.bmp` |
| **TIFF** | `.tiff`, `.tif` |
| **Icon** | `.ico` |
